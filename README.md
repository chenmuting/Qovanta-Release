## 项目简介

Qovanta 是一款 HarmonyOS 应用，用于配置、发送和管理 HTTP 请求。它支持从响应中提取数据、对提取结果做转换与条件筛选、通过图表组件对数据做可视化展示、通过占位符复用环境变量或运行时参数，并将多个接口编排为可顺序执行的串联链。

应用包含首页、串联链、环境和设置四个主页面；可进入接口结果、接口编辑、串联链详情、串联链编辑、通用设置、个性化、数据备份、数据清除、日志和关于等页面。应用适配手机、平板与 2in1 设备，宽屏下自动切换分栏导航与双列列表布局。

## 功能特性

### 接口调试

- 支持 GET、POST、PUT、DELETE、PATCH、HEAD、OPTIONS。
- 支持请求头、查询参数、JSON、Form URL-Encoded 与 Raw 请求体。
- 支持 Bearer Token、Basic Auth 和 API Key 认证。
- 支持接口分组、下拉筛选、启动时自动请求、添加、编辑、删除和下拉刷新。
- 支持将接口配置复制为副本，并选择目标分组。
- 支持粘贴 cURL 命令导入配置，以及复制当前请求对应的 cURL。
- 支持长按卡片进入多选模式（首页、串联链、环境页通用），批量删除、批量指派分组，支持全选当前筛选结果。
- 支持通过二维码分享单个接口配置（自动脱敏凭据），以及首页扫一扫导入配置。
- 响应体支持「树视图 / 原文」切换：JSON 响应按层级树形浏览，节点可折叠展开。

### 占位符与动态参数

可在 URL、请求头、查询参数、请求体和认证字段中使用 `{{...}}` 占位符：

| 类型 | 语法 | 说明 |
| --- | --- | --- |
| 串联链变量 | `{{key}}` | 使用前置步骤的提取结果 |
| 运行时输入 | `{{input:key}}` | 发送时填写，不写入配置 |
| 运行时密钥 | `{{secret:key}}` | 发送时以密码框填写，不写入配置 |
| 运行时选择 | `{{select:key}}` | 发送时从预设变量选项中下拉选择，不写入配置 |
| 环境变量 | `{{env:key}}` | 使用当前启用环境中的变量 |
| 动态函数 | `{{fn:name}}` | 自动生成时间、随机数或编解码结果 |

- 支持 `{{key|默认值}}` 后备值和嵌套占位符。
- 内置时间、随机、UUID、Base64 / URL 编解码、MD5 / SHA 系列、HMAC 签名、CRC-32、JSONPath、大小写转换与设备信息等动态函数。

详细语法见 [占位符使用文档](docs/占位符使用文档.md)。

### 环境与预设变量

- 环境变量页提供「环境变量 / 预设变量」分段切换，环境选择与新增入口统一在顶部导航菜单。
- 可创建、重命名、删除和切换环境分组。
- 支持变量的新增、编辑、删除、复制为副本，以及复制 `{{env:key}}` 引用。
- 变量可标记为密文：列表中会遮罩显示，导出备份时其值为空。
- 预设变量：为 `{{select:key}}` 占位符配置可选项（标签 - 值），发送时以下拉框选择；预设变量可随配置一起导入导出。

### 响应提取与结果处理

- JSON 使用 `$.` 路径提取普通值、数组、数组字段、对象键名与键值、数量和存在性结果；HTML 使用标准 XPath 1.0 表达式（13 条轴、`and/or`、比较与算术运算、并集 `|`、`count()`/`boolean()`/`string()`/`normalize-space()` 等核心函数），响应按容错模式解析；均支持 `?? 默认值` 失败兜底。
- 提取结果可复制，并可作为串联链后续步骤的输入。
- 支持对指定规则或全部规则执行正则替换；支持分组引用和常用转义序列。
- 每条提取规则支持链式数据转换：时间戳与日期互转、Base64 / URL 编解码、JSON 格式化和去除空白，多个转换用 `>` 串联依次执行。
- 支持对提取结果配置执行条件：采用 if / else if / else 分支链模型，每个分支可组合多个条件（且/或），命中首个成立分支即输出其结果；提供 11 种比较操作符，期望值与输出支持 `{{fn:...}}` 动态函数（如与当前时间比较）。
- 结果处理不修改原始响应内容或请求配置。

详细说明见 [提取规则文档](docs/提取规则文档.md)、[执行条件文档](docs/执行条件文档.md) 与 [正则规则文档](docs/正则规则文档.md)。

### 结果页与数据可视化

- 点击首页接口卡片进入独立的接口结果页，「提取结果」与「可视化」双页签切换。
- 提取结果页逐条展示规则名称、路径与提取值（数组结果标注元素数量，支持展开收起），提供「复制提取值」与「复制提取键值」批量复制。
- 结果页右上角可手动刷新重发请求；配置了运行时占位符时先弹出「运行时参数」填写面板。
- 尚未获取数据时展示提取规则预览（规则名、数据源与路径），无提取规则时给出提示。
- 可视化页签以图表组合展示提取结果，支持四种图表类型：表格、柱状图、折线图、饼图。
- 每个图表可绑定一个或多个提取规则作为数据列，并指定一条规则作为分类标签；柱状图与折线图支持垂直 / 水平方向，可添加多个数值系列。
- 图表支持「排序」（默认顺序 / 数值从高到低 / 数值从低到高）与「查看前 N 项」（5 / 10 / 20 / 30 / 50 项）筛选，支持全屏查看（自动切换横屏）。
- 图表组合按接口持久化保存，随提取结果自动更新。

### 接口串联链

- 将多个接口按顺序编排为可复用的工作流。
- 点击串联链进入独立的链详情页：逐步展示执行状态与提取结果，运行中可随时停止。
- 编辑页可多选接口一次性批量添加步骤。
- 前置步骤的提取结果可映射到后续步骤的占位符。
- 支持每步“中止”或“跳过”错误策略。
- 支持自定义链输出模板，以及数组结果的选择性批量执行（选择面板支持全选，单次最多 500 项）。
- 支持将串联链复制为副本，并选择目标分组。

### 数据备份与恢复

- 可导出到本地 JSON 文件，也可从文件恢复；导入前进入预览页面，可按接口、串联链、环境分组、单个环境变量、预设变量五类粒度勾选导入内容。
- 支持通过 WebDAV 在多设备间同步备份。

### 运行日志与通用设置

- 支持等级筛选（DEBUG/INFO/WARN/ERROR）、关键字搜索、导出 TXT 和清空。
- 「通用」设置页提供「HTTP 调试」开关：默认允许 HTTP 明文请求，关闭后拦截所有 `http://` 请求。
- 「通用」设置页支持全局默认请求头，以及请求超时（5~60 秒）、失败重试次数与重试间隔的全局配置，接口级设置可覆盖全局值。

### 多设备适配

- 正式支持平板与 2in1 设备，手机、平板与 2in1 共用一个安装包。
- 按窗口宽度自动识别 SM / MD / LG 断点，布局随窗口尺寸实时切换。
- 宽屏下底部页签自动切换为侧边垂直页签；大屏启用分栏模式，栏宽可拖拽调节。
- 首页与串联链列表在中等宽度下双列展示；接口编辑、设置等页面内容居中限宽。
- 宽屏下底部弹层自动切换为居中弹窗。
- 图表支持全屏查看并自动切换横屏；键盘与鼠标交互在平板 / 2in1 下正常工作。
