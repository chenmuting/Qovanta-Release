## 项目简介

Qovanta 是一款 HarmonyOS 应用，用于配置、发送和管理 HTTP 请求。它支持从响应中提取数据、对提取结果做转换与条件筛选、通过占位符复用环境变量或运行时参数，并将多个接口编排为可顺序执行的串联链。

应用包含首页、串联链、环境和设置四个主页面；可进入接口编辑、串联链编辑、个性化、数据备份、数据清除、日志和关于等页面。

## 功能特性

### 接口调试

- 支持 GET、POST、PUT、DELETE、PATCH、HEAD、OPTIONS。
- 支持请求头、查询参数、JSON、Form URL-Encoded 与 Raw 请求体。
- 支持 Bearer Token、Basic Auth 和 API Key 认证。
- 支持接口分组、下拉筛选、启动时自动请求、添加、编辑、删除和下拉刷新。
- 支持粘贴 cURL 命令导入配置，以及复制当前请求对应的 cURL。
- 支持长按卡片进入多选模式，批量删除接口、批量指派分组，支持全选当前筛选结果。
- 支持通过二维码分享单个接口配置（自动脱敏凭据），以及首页扫一扫导入配置。

### 占位符与动态参数

可在 URL、请求头、查询参数、请求体和认证字段中使用 `{{...}}` 占位符：

| 类型 | 语法 | 说明 |
| --- | --- | --- |
| 串联链变量 | `{{key}}` | 使用前置步骤的提取结果 |
| 运行时输入 | `{{input:key}}` | 发送时填写，不写入配置 |
| 运行时密钥 | `{{secret:key}}` | 发送时以密码框填写，不写入配置 |
| 环境变量 | `{{env:key}}` | 使用当前启用环境中的变量 |
| 动态函数 | `{{fn:name}}` | 自动生成时间、随机数或编解码结果 |

- 支持 `{{key|默认值}}` 后备值和嵌套占位符。
- 内置时间、随机、UUID、Base64、MD5、SHA-256 和 URL 编码等动态函数。

详细语法见 [占位符使用文档](docs/占位符使用文档.md)。

### 环境变量

- 可创建、重命名、删除和切换环境分组。
- 支持变量的新增、编辑、删除，以及复制 `{{env:key}}` 引用。
- 变量可标记为密文：列表中会遮罩显示，导出备份时其值为空。

### 响应提取与结果处理

- JSON 使用 `$.` 路径提取普通值、数组、数组字段、数量和存在性结果；HTML 使用 XPath 子集表达式。
- 提取结果可复制，并可作为串联链后续步骤的输入。
- 支持对提取结果执行正则替换；支持分组引用和常用转义序列。
- 每条提取规则支持链式数据转换：时间戳与日期互转、Base64 / URL 编解码、JSON 格式化和去除空白。
- 支持对提取结果配置 if / else if / else 执行条件，命中首个成立分支即输出其结果。

详细说明见 [提取规则文档](docs/提取规则文档.md)、[执行条件文档](docs/执行条件文档.md) 与 [正则规则文档](docs/正则规则文档.md)。

### 接口串联链

- 将多个接口按顺序编排为可复用的工作流。
- 前置步骤的提取结果可映射到后续步骤的占位符。
- 支持每步“中止”或“跳过”错误策略。
- 支持自定义链输出模板，以及数组结果的选择性批量执行（单次最多 500 项）。

### 数据备份与恢复

- 可导出到本地 JSON 文件，也可从文件恢复；导入前可按接口、串联链、环境等粒度勾选内容。
- 支持通过 WebDAV 在多设备间同步备份。

### 运行日志

- 支持等级筛选、关键字搜索、导出 TXT 和清空。
- 设置页提供「HTTP 调试」开关，可拦截所有 `http://` 明文请求。
