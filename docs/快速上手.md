# 快速上手

本指南带你完成从创建接口到运行串联链的基本流程。

## 1. 创建第一个接口

1. 打开 Qovanta，默认进入「首页」。
2. 点击右下角添加按钮，进入接口编辑页。
3. 填写基本信息：
   - **名称**：如 `获取用户信息`
   - **请求方式**：选择 `GET`
   - **URL**：如 `https://api.example.com/users/1`
4. 点击保存，回到首页。

## 2. 发送请求

1. 在首页列表中点击接口卡片，进入详情页。
2. 点击「发送」，查看响应状态码、响应头和响应体。
3. 可在详情页快速复制响应内容，或点击复制 cURL 命令到剪贴板。

## 3. 使用环境变量

1. 切换到「环境」页签，点击添加，创建一个环境（如 `测试环境`）。
2. 在环境中添加变量，例如 `host` = `https://api.example.com`。
3. 在接口 URL 中改用 `{{env:host}}/users/1`，并启用该环境。
4. 再次发送请求，占位符会自动替换为变量值。

更多占位符用法见 [占位符使用文档](占位符使用文档.md)。

## 4. 从响应中提取数据

1. 在接口编辑或详情页打开「提取规则」。
2. 添加一条规则：格式选 `JSON`，路径填 `$.name`。
3. 发送请求后，可在结果区查看提取值并复制。

提取语法详见 [提取规则文档](提取规则文档.md)。

## 5. 创建串联链

1. 切换到「串联链」页签，点击添加。
2. 从接口列表中依次选择要串联的接口作为步骤。
3. 在后续步骤中使用前置步骤的提取结果：例如步骤 1 提取了 `token`，步骤 2 的请求头可写 `{{token}}`。
4. 保存后点击运行，按顺序执行并查看每步结果。

## 6. 备份数据

1. 进入「设置 → 数据备份」。
2. 选择导出到本地文件（默认 `Qovanta_backup.json`），或配置 WebDAV 远程同步。
3. 换机或重装后，可从备份文件恢复，导入前可勾选需要的内容。
