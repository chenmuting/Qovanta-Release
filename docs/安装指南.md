# 安装指南

## 系统要求

- HarmonyOS 手机（兼容 SDK 26.0.0）
- 足够的存储空间（安装包与备份数据）

## 下载安装包

1. 进入本仓库的 [Releases](../releases) 页面。
2. 选择最新版本，在 Assets 中下载 `.hap`（或 `.app`）安装包。

> 建议始终使用最新正式版本；预发布（Pre-release）版本可能不稳定。

## 安装步骤

### 方式一：文件管理器安装

1. 将下载的安装包传输到手机（可通过数据线、局域网共享或聊天工具发送）。
2. 在手机的文件管理器中找到安装包，点击安装。
3. 若提示“禁止安装未知来源应用”，按系统指引允许当前来源安装。

### 方式二：命令行安装（hb/hdc）

适用于开发者或 adb/hdc 工具用户：

```bash
hdc install entry-signed-release.hap
```

## 常见问题

### 提示安装失败或签名校验不通过

安装包使用发布证书签名，若安装失败请确认：

- 下载的安装包完整（对比 Releases 页面公布的文件大小或校验值）。
- 手机系统版本满足要求。
- 旧版本应用使用的是相同签名（不同签名的版本需先卸载旧版再安装）。

### 升级会丢失数据吗

正常覆盖升级不会丢失数据。接口配置、串联链、环境变量等数据保存在应用数据目录中，卸载应用会连同清除，建议升级前先通过「设置 → 数据备份」导出备份文件。

### 如何完全卸载

长按应用图标卸载即可。应用数据（配置、数据库、日志）会一并删除，如有需要请先导出备份。
