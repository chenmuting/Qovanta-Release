# 提取规则文档

---

## 一、功能概述

「提取规则」用于从**接口响应体**中按路径抽取需要的数据。每条规则包含名称、解析格式（`source`）与路径表达式（`path`）三部分。发送请求得到响应体后，系统按规则的解析格式分发到对应解析器：

- `JSON`：使用 JSON 路径语法（类 JSONPath 子集）；
- `HTML`：使用 HTML XPath 子集语法。

提取得到的结果会继续进入正则清理、值转换、条件判断等二次处理环节，并最终展示在响应结果面板、首页卡片，或作为链式请求的变量参与后续步骤。提取失败的规则会跳过后续的清理、转换与条件判断；执行条件在全部规则完成提取与二次处理后统一运行，因此支持跨规则的数组对齐（详见《执行条件文档》）。

> 当数组结果被串联链后续步骤引用时，是否弹出选择面板由来源步骤的完整提取结果决定：混有单值与数组（或数组仅一个元素）时整体按单值处理；全部为等长数组时按行对齐选择，选中后按行迭代执行后续步骤；长度不等时依次弹出各组选择面板。详见《占位符使用文档》串联链变量一节。

处理链路：

```text
发送请求
  → 响应体
  → 提取规则（ExtractionRule，按 source 分发 JSON / HTML 解析）   ← 本文档环节
  → 正则清理规则（RegexCleanRule）
  → 值转换 / 条件判断
  → 提取结果展示（响应面板 / 首页卡片）
  → 链式请求变量绑定、输出映射
```

**重要**：提取规则只读取响应体，不修改任何请求内容；单条规则解析失败时可通过 `| 默认值` 兜底（见第四节）。

## 二、通用规则

以下约定对 JSON 与 HTML 两种格式均适用。

### 2.1 默认值语法 `| 默认值`

在路径末尾追加 `|` 与默认值，当提取失败（路径不存在、类型不符、解析异常）时返回该默认值。

| 示例 | 含义 |
|------|------|
| `data.token \| 无` | 取不到 token 时返回「无」 |
| `//h1/text() \| 默认标题` | 取不到标题时返回「默认标题」 |
| `data.list[].count \| 0` | 数组不存在时返回「0」 |

- 分隔符是**第一个** `|` 字符，其左侧为路径、右侧为默认值。
- 默认值可以为空（`path|`），表示失败时返回空字符串且规则仍算「成功」。

### 2.2 结果类型

提取结果分为单值与多值：

- **单值（VALUE）**：命中唯一结果，直接返回文本。
- **数组（ARRAY）**：命中多个结果，`value` 用换行 `\n` 连接，同时保留 `values` 数组供链式请求逐项使用。
- **计数（COUNT）** / **存在（EXISTS）**：返回数量或 `true`/`false`。

### 2.3 文本处理

- JSON 字符串值会自动去除首尾引号并反转义（`\n`、`\t`、`\uXXXX`、代理对等）。
- HTML 取出的文本会**归一化空白**：连续空白折叠为单个空格并 trim，`<br>` 转为空格，并解码常见 HTML 实体。

### 2.4 批量拆分多条规则

路径输入框支持一次粘贴**多行路径**（每行一条）：保存时非空行多于 1 行会自动拆分——第 1 行保留在当前规则，其余每行各生成一条新规则，名称与解析格式沿用当前规则。适合从接口文档一次性搬运多个字段路径。

## 三、JSON 提取语法

目标类型由路径后缀自动推断，无需手动选择。

### 3.1 根与对象字段

| 语法 | 含义 | 示例 |
|------|------|------|
| `$` | 根节点自身 | `$` → 整个响应体 |
| `$.field` | 根下的字段（`$.` 可省略） | `$.code` 等价于 `code` |
| `a.b.c` | 逐级访问对象字段 | `data.user.name` |

- `$` 或 `$.` 前缀会被归一化去除。
- 字段名通过精确匹配 `"key"` 定位，区分大小写。

示例响应：

```json
{ "code": 0, "data": { "user": { "name": "Ada", "age": 30 } } }
```

| 路径 | 结果 |
|------|------|
| `code` | `0` |
| `data.user.name` | `Ada` |
| `data.user.age` | `30` |

### 3.2 数组下标

用 `[n]` 访问数组第 n 个元素（下标从 0 开始）。可紧跟字段名，也可对根数组直接取值。

| 语法 | 含义 |
|------|------|
| `list[0]` | list 数组第 1 个元素 |
| `data.items[2].id` | items 第 3 项的 id 字段 |
| `[0]` | 根数组第 1 个元素 |

示例响应：

```json
{ "list": [ { "id": "a1" }, { "id": "b2" }, { "id": "c3" } ] }
```

| 路径 | 结果 |
|------|------|
| `list[0].id` | `a1` |
| `list[2].id` | `c3` |

### 3.3 数组展开 `[]`（取整组）

在数组路径末尾加 `[]`，表示取出该数组的**全部元素**，返回数组结果（ARRAY）。

| 语法 | 含义 |
|------|------|
| `data[]` | 取 data 数组的所有元素 |
| `data.ids[]` | 取 data.ids 数组的所有元素 |

示例响应：

```json
{ "data": ["a1", "b1", "a2"] }
```

| 路径 | 结果（换行连接） |
|------|------|
| `data[]` | `a1` / `b1` / `a2` 三项 |

### 3.4 数组字段展开 `[].key`（批量取字段）

对**对象数组**，在 `[]` 后加 `.字段名`，可批量取出每个对象的该字段，返回数组（ALL_KEYS）。

示例响应：

```json
{ "list": [ { "id": "a1", "name": "甲" }, { "id": "b2", "name": "乙" } ] }
```

| 路径 | 结果 |
|------|------|
| `list[].id` | `a1` / `b2` |
| `list[].name` | `甲` / `乙` |

- 某个元素缺少该字段时会跳过该项。
- `[].count`、`[].exists`、`[].*` 属于保留后缀，不作为普通字段展开。

### 3.5 计数 `[].count`

在数组路径末尾加 `[].count`，返回数组元素个数（COUNT）。

| 路径 | 含义 |
|------|------|
| `data[].count` | data 数组长度 |
| `data.list[].count` | data.list 数组长度 |

示例：`{ "data": ["a1","b1","a2"] }` → `data[].count` = `3`。

- 若目标不是数组，返回空或默认值。

### 3.6 存在判断 `[].exists`

在路径末尾加 `[].exists`，判断目标是否存在，返回 `true` / `false`（EXISTS）。

| 路径 | 含义 |
|------|------|
| `data.token[].exists` | token 是否存在 |
| `data.list[].exists` | list 是否存在 |

- 判断依据是「原始值非空」。

### 3.7 JSON 语法速查

| 语法 | 目标类型 | 说明 |
|------|----------|------|
| `$` / 空 | VALUE | 根节点 |
| `a.b.c` | VALUE | 逐级字段 |
| `arr[n]` | VALUE | 数组下标 |
| `arr[n].key` | VALUE | 下标后取字段 |
| `arr[]` | ARRAY | 取整个数组 |
| `arr[].key` | ALL_KEYS | 批量取对象字段 |
| `arr[].count` | COUNT | 数组长度 |
| `arr[].exists` | EXISTS | 是否存在 |
| `path \| 默认值` | — | 失败兜底 |

## 四、HTML 提取语法（XPath 子集）

这是一套自研 XPath 子集，仅实现最常用的定位与取值能力，**不是完整 XPath**。

### 4.1 整体结构

```text
定位路径[谓词]...[/取值步] | 默认值
```

- 表达式必须以 `/` 或 `//` 开头，否则判定为无效路径、提取失败。
- 末尾可选 `| 默认值` 兜底。

### 4.2 轴（层级关系）

只支持两种轴：

| 写法 | 含义 |
|------|------|
| `/` | 直接子节点 |
| `//` | 任意层级后代（递归） |

不支持父轴、兄弟轴、祖先轴（无 `..`、`following-sibling` 等）。

### 4.3 节点测试（标签名）

- 直接写标签名，如 `div`、`a`、`span`，解析时统一转小写。
- 支持通配 `*` 匹配任意元素。
- 标签名不能含空格或 `/`。

示例：`//ul/li`、`//*[@id='main']`

### 4.4 谓词 `[...]`（过滤条件）

同一步可串联多个谓词 `[..][..]`，按顺序依次过滤。支持以下几类：

| 谓词 | 含义 | 示例 |
|------|------|------|
| `[n]` | 位置（≥1，**按各自父节点分组计数**） | `//ul/li[1]` |
| `[last()]` | 每组最后一个（同样按父节点分组） | `//li[last()]` |
| `[last()-n]` | 每组倒数第 n+1 个（`-` 前后可加空格，偏移须为非负整数） | `//li[last()-1]` |
| `[@attr]` | 属性存在且非空 | `//a[@href]` |
| `[@attr='value']` | 属性精确等于（区分大小写，值需引号） | `//div[@class='item']` |
| `[@attr!='value']` | 属性值不等于；**没有该属性的节点也会命中** | `//a[@class!='active']` |
| `[contains(@attr,'value')]` | 属性包含子串 | `//div[contains(@class,'card')]` |
| `[contains(text(),'value')]` | 文本包含子串（按归一化后文本判断） | `//button[contains(text(),'下一页')]` |
| `[starts-with(@attr,'value')]` | 属性值以 value 开头 | `//a[starts-with(@href,'/a')]` |
| `[starts-with(text(),'value')]` | 文本以 value 开头（按归一化后文本判断） | `//a[starts-with(text(),'首')]` |
| `[not(...)]` | 对内部谓词取反（可嵌套；内部不能是位置谓词） | `//a[not(@class='active')]` |

注意事项：

- 位置谓词是**每个父节点下**的第 n 个，而非全局第 n 个。例如 `//li[1]` 会选中每个列表的首项；`[last()]` / `[last()-n]` 同样按父节点分组、从末位计数。
- 属性等值与不等值的值**必须用单引号或双引号包裹**，否则整条路径无效。
- `!=` 以「属性不存在视为空串」参与比较，因此没有该属性的节点也满足 `[@attr!='value']`。
- `contains(...)` / `starts-with(...)` 第一个参数只能是 `text()` 或 `@属性名`，第二个参数必须是非空引号字符串。
- `not(...)` 内部可以是任意属性/文本谓词（含 `!=`、`contains`、`starts-with`），也允许嵌套 `not(not(...))`；内部为位置谓词（`[n]`、`last()`）时整条路径无效。
- 谓词内**不支持** `and` / `or` / `position()>1` 等组合与比较运算（取反用 `not()`，末位用 `last()`）。

### 4.5 取值步（末尾决定取什么）

| 写法 | 含义 |
|------|------|
| `.../text()` | 取节点文本内容 |
| `.../@attr` | 取节点属性值（属性为空则跳过该节点） |
| 不写取值步 | 默认取节点文本，等价于 `text()` |

示例：

- `//h1/text()` → 标题文本
- `//a[@class='next']/@href` → 链接地址
- `//title` → 等价于 `//title/text()`

### 4.6 包裹函数

整条表达式可被包一层函数：

| 函数 | 含义 | 示例 |
|------|------|------|
| `count(路径)` | 返回匹配节点数量 | `count(//ul/li)` → `12` |
| `boolean(路径)` | 有匹配返回 `true`，否则 `false` | `boolean(//div[@id='error'])` |

### 4.7 解析器容错与限制

- 自动跳过注释 `<!-- -->`、`<!doctype>`、`<?...?>`。
- 正确处理自闭合标签、void 标签（`br/img/input` 等）、原始文本标签 `script`/`style`。
- 支持常见标签的隐式闭合：`li/p/option/dt/dd` 同名互闭，以及 `td/th/tr` 表格结构。
- 安全上限：最多解析 20000 个节点，单段文本最长 512KB。

### 4.8 HTML 语法速查

```text
//title/text()                              页面标题
//div[@class='price']/text()                指定 class 的价格文本
//a[@id='download']/@href                   下载链接地址
//ul[@class='list']/li/text()               列表所有项（数组）
//div[contains(@class,'card')]//h3/text()   卡片标题
//li[last()]/a/text()                        每组列表最后一项的链接文本
//a[@class!='active']/@href                  非 active 的链接（含无 class 的节点）
//a[starts-with(@href,'/a')]/text()          以 /a 开头的链接文本
//a[not(@class='active')]/@href              用 not() 取反过滤
//tr[2]/td[1]/text()                         每个表格第 2 行第 1 格
count(//div[@class='item'])                 条目数量
boolean(//span[@class='sold-out'])          是否售罄
//meta[@name='keywords']/@content | 无      带默认值兜底
```

## 五、JSON 与 HTML 对比

| 能力 | JSON | HTML |
|------|------|------|
| 逐级定位 | `a.b.c` | `/a/b/c`、`//c` |
| 下标/位置 | `arr[n]` | `elem[n]`（按父分组） |
| 取整组 | `arr[]` | 多命中自动返回数组 |
| 批量取字段/属性 | `arr[].key` | `//elem/@attr`、`//elem/text()` |
| 计数 | `arr[].count` | `count(路径)` |
| 存在判断 | `arr[].exists` | `boolean(路径)` |
| 条件过滤 | 不支持 | `[@attr='v']`、`[@attr!='v']`、`[contains(...)]`、`[starts-with(...)]`、`[not(...)]` |
| 默认值 | `path \| 默认值` | `path \| 默认值` |

## 六、常见问题

**Q1：路径取不到值？**
先确认解析格式（`source`）是否与响应体一致（JSON 响应用 JSON、网页用 HTML）；再检查路径大小写、引号是否正确。可临时加 `| 调试值` 观察是否走了默认值分支。

**Q2：HTML 属性等值不生效？**
属性值必须加引号：`//a[@class='btn']`，写成 `//a[@class=btn]` 会导致整条路径无效。

**Q3：`//li[1]` 为什么返回多条？**
位置谓词是「每个父节点下的第 n 个」。若只想要全局首项，可用更精确的父级定位，如 `//ul[@id='main']/li[1]`。

**Q4：想批量拿到对象数组里的某个字段？**
JSON 用 `list[].字段名`（如 `list[].id`）；HTML 用 `//项容器/子元素/text()` 或 `/@attr`，多命中会自动返回数组。

**Q5：提取到的字符串带引号或转义？**
JSON 字符串已自动去引号并反转义；若仍需进一步清洗（如去 HTML 标签、截取分组），使用「正则清理」二次处理（见《正则规则文档》）。
