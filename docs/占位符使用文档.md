# 占位符使用文档

Qovanta 用一套统一的 `{{...}}` 占位符语法，把「接口配置」变成可复用的模板。同一份配置可以在不同环境、不同参数、不同时间戳下反复执行，无需手工改写。

本文覆盖全部占位符的语法、默认值、解析时机、转义规则与组合用法。

---

## 1. 五类占位符总览

| 类型 | 语法 | 值的来源 | 解析时机 |
|------|------|---------|---------|
| 运行时输入 | `{{input:名称}}` | 发送前弹窗，用户手填 | 点击发送/执行时 |
| 运行时密钥 | `{{secret:名称}}` | 发送前弹窗，密码框输入 | 点击发送/执行时 |
| 环境变量 | `{{env:变量名}}` | 「环境变量」页当前环境 | 请求发出前自动读取 |
| 动态变量 | `{{fn:函数名}}` | 内置函数自动求值 | 请求发出前自动计算 |
| 串联链变量 | `{{任意名称}}`（无前缀） | 前置步骤的提取规则 | 串联链执行到该步时 |

> 无前缀的占位符一律视为串联链变量。前缀 `input:` / `secret:` / `env:` / `fn:` 是保留字，不要用作串联链变量名。

### 解析顺序

一次请求发出前，占位符按固定顺序逐层替换：

```
串联链变量注入  →  运行时输入弹窗  →  环境变量  →  动态变量  →  发出请求
   {{token}}        {{input:x}}       {{env:k}}    {{fn:...}}
```

这个顺序是有意设计的：**靠后的类型可以看到靠前类型替换后的结果**。因此 `{{fn:md5:{{env:appSecret}}}}` 能正常工作——`{{env:appSecret}}` 先被换成真实值，`fn:md5` 再对结果求摘要。反之则不成立（不能用动态变量的结果去索引环境变量名）。

## 2. 通用语法规则

### 2.1 可用位置

| 位置 | 示例 |
|------|------|
| URL | `https://{{env:host}}/items/{{itemId}}` |
| 请求头值 | `X-Sign: {{fn:md5:abc}}` |
| 查询参数值 | `ts={{fn:timestamp}}` |
| 请求体（JSON / Form / Raw） | `{"token":"{{token}}"}` |
| Bearer Token | `{{env:token}}` |
| API Key 名称 / 值 | `{{env:apiKeyName}}` |

请求头的**名称**、查询参数的**名称**不参与占位符替换，只有值参与。

此外，**执行条件**的期望值与输出字段也支持 `{{fn:...}}` 动态函数（如用 `{{fn:timestamp}}` 与过期时间比较），在提取执行时解析；详见《执行条件文档》。

### 2.2 自动转义

同一个值注入到不同位置时，系统按目标格式自动做安全处理，无需手工编码：

| 目标位置 | 处理方式 |
|---------|---------|
| URL | URL 安全字符转义（空格 → `%20`） |
| 请求头值 / Token / API Key | 剥离 `\r` `\n` 与 NUL 字符，防响应头注入 |
| 查询参数值 | 保留原样（由网络层统一编码） |
| JSON 请求体 | 位于 JSON 字符串内时做字符串转义（`"` → `\"`、换行 → `\n`）；处于字符串外的裸值位置时原样注入 |
| Form 请求体 | `application/x-www-form-urlencoded` 编码 |
| Raw 请求体 | 保留原样 |

### 2.3 默认值：`{{key|默认值}}`

任意类型的占位符都可以在键名后以竖线添加默认值：

| 写法 | 行为 |
|------|------|
| `{{env:host|api.example.com}}` | 当前环境没有 `host` 时使用 `api.example.com` |
| `{{input:page|1}}` | 未填写或未解析时使用 `1` |
| `{{orderId|unknown}}` | 串联链未注入 `orderId` 时使用 `unknown` |
| `{{fn:unknown|fallback}}` | 动态函数不受支持时使用 `fallback` |

默认值只会在该占位符经过串联链变量、运行时输入、环境变量与动态变量全部解析后仍未替换时生效；环境变量与运行时输入即使取到空字符串，也视为已解析、不改用默认值（串联链变量是例外：前置步骤提取结果为空字符串时不注入，仍会走默认值兜底）。

默认值可以包含嵌套占位符，嵌套占位符继续按既有解析顺序处理：

```
{{env:host|{{env:fallbackHost}}}}
{{fn:md5:{{env:appSecret}}|unsigned}}
```

竖线仅在占位符最外层生效；嵌套占位符中的竖线属于嵌套内容。例如 `{{fn:md5:{{env:secret|default}}|unsigned}}` 的动态函数参数默认值是 `default`，整个摘要占位符的默认值是 `unsigned`。

### 2.4 未识别的占位符

- 未定义的环境变量：请求照常发出，并 Toast 提示「以下环境变量未定义：xxx」
- 未知的动态函数名：写入警告日志，不阻断请求
- 未映射的串联链变量：不注入，继续走默认值兜底

请求发出前的最后一步是**默认值兜底**：凡是仍未解析的占位符，有默认值（`| 默认值`）时替换为默认值，没有默认值时替换为**空字符串**，不会以 `{{...}}` 字面量出现在请求中。排查「字段值意外为空」时优先检查占位符拼写与变量定义。

### 2.5 cURL 预览不泄露真实值

配置页始终显示的 cURL 命令基于**未解析**的配置生成，占位符保持字面量，可以安全分享。发送请求后响应区展示的 cURL 则是实际发出的那一条，包含求值后的真实内容。

## 3. 运行时输入：`{{input:}}` 与 `{{secret:}}`

适用于每次执行都可能不同、且不适合落库的值（验证码、临时口令、一次性单号）。

```
https://api.example.com/login?user={{input:username}}
{"password":"{{secret:password}}"}
```

- 点击发送或执行串联链时，弹出运行时参数面板，逐项填写
- `input:` 用普通输入框，`secret:` 用密码框（内容遮罩）
- 全部为必填项，任一为空无法继续
- 填写值只在本次执行的内存中使用，不写入数据库
- 同名占位符（如两处都写 `{{input:username}}`）只需填一次，全部替换

## 4. 环境变量：`{{env:}}`

适用于同一套接口在多环境间切换的值（域名、租户 ID、长期令牌）。

### 4.1 定义变量

在底部「环境变量」页：

1. 新建环境（如 `开发`、`预发`、`生产`）
2. 在环境下新增变量，填写变量名与变量值
3. 在顶部环境栏选中目标环境，点击 **设为当前环境**（该环境显示「使用中」标记）

变量名只能包含字母、数字、下划线、短横线和点；同一环境内不允许重名。变量卡片提供「复制引用」，直接得到 `{{env:变量名}}` 文本。

### 4.2 引用变量

```
URL:      https://{{env:baseUrl}}/v1/orders
请求头:    Authorization: Bearer {{env:token}}
```

解析时只读取**当前环境**的变量表。切换环境后，所有引用该变量名的接口自动指向新值，无需逐个修改配置。

### 4.3 密文变量

变量可勾选「按密文处理」：

- 列表中以 `••••••` 遮罩显示
- 导出配置备份时不包含该值

注意：密文仅作界面遮罩与导出剔除，本地数据库中仍为明文存储。高敏令牌建议改用 `{{secret:}}` 运行时输入。

---

## 5. 动态变量：`{{fn:}}`

发送前自动求值，无需人工填写，也不参与串联链映射。主要用于时间戳、随机数、签名这三类「每次请求都必须变」的字段。

### 5.1 语法

```
{{fn:函数名}}
{{fn:函数名:参数}}
{{fn:函数名±偏移秒}}
```

- 函数名**大小写不敏感**（`fn:timestampMs` 与 `fn:TIMESTAMPMS` 等价）
- 参数从函数名后的**第一个冒号**开始，其后所有内容都算参数（因此参数里可以带冒号，如 `{{fn:base64:user:pass}}`）
- `±偏移秒` 只对时间类函数生效，其他函数会忽略

### 5.2 时间类

以下示例假设当前时刻为时间戳 `1700000000`（UTC 2023-11-14 22:13:20），设备时区为 UTC+8。

| 占位符 | 说明 | 结果示例 |
|-------|------|---------|
| `{{fn:timestamp}}` | 秒级时间戳 | `1700000000` |
| `{{fn:timestamp+3600}}` | 秒级时间戳 + 1 小时 | `1700003600` |
| `{{fn:timestamp-300}}` | 秒级时间戳 - 5 分钟 | `1699999700` |
| `{{fn:timestampMs}}` | 毫秒级时间戳 | `1700000000000` |
| `{{fn:isoDate}}` | ISO 8601（UTC） | `2023-11-14T22:13:20.000Z` |
| `{{fn:date}}` | 本地日期 | `2023-11-15` |
| `{{fn:time}}` | 本地时间 | `06:13:20` |
| `{{fn:datetime}}` | 本地日期时间 | `2023-11-15 06:13:20` |
| `{{fn:timezone}}` | 本地时区偏移 | `+08:00` |

`date` / `time` / `datetime` 支持用参数自定义格式：

| 占位符 | 结果示例 |
|-------|---------|
| `{{fn:datetime:yyyyMMddHHmmss}}` | `20231115061320` |
| `{{fn:date:yyyy/MM/dd}}` | `2023/11/15` |
| `{{fn:datetime:yyyy-MM-dd HH:mm:ss.SSS}}` | `2023-11-15 06:13:20.000` |

格式占位符：

| 符号 | 含义 | 符号 | 含义 |
|------|------|------|------|
| `yyyy` | 四位年 | `HH` | 24 小时制时（补零） |
| `yy` | 两位年 | `mm` | 分（补零） |
| `MM` | 月（补零） | `ss` | 秒（补零） |
| `dd` | 日（补零） | `SSS` | 毫秒（补零到三位） |

其余字符原样输出，可自由插入 `-` `/` `:` 空格等分隔符。

格式与偏移可同时使用，偏移写在函数名之后、参数之前：`{{fn:datetime+86400:yyyy-MM-dd}}` 得到明天的日期。

> `isoDate` 固定按 UTC 输出；`date` / `time` / `datetime` / `timezone` 按设备本地时区输出。

### 5.3 随机类

| 占位符 | 说明 | 结果示例 |
|-------|------|---------|
| `{{fn:uuid}}` | 标准 UUID v4（含短横线） | `9f1c8e4a-...-4b2d` |
| `{{fn:nonce}}` | 16 位随机串 | `Xk3mQz9PtR2wLbA7` |
| `{{fn:nonce:8}}` | 指定长度随机串 | `Qz9PtR2w` |
| `{{fn:randomString}}` | 16 位随机串（同 nonce） | `bA7Xk3mQz9PtR2wL` |
| `{{fn:randomString:32}}` | 32 位随机串 | — |
| `{{fn:randomInt}}` | 0 ~ 999999 随机整数 | `481902` |
| `{{fn:randomInt:100}}` | 0 ~ 100 随机整数 | `73` |
| `{{fn:randomInt:10-20}}` | 10 ~ 20 随机整数（含两端） | `14` |

- 随机串字符集为大小写字母 + 数字，长度上限 256（超出按 256 处理），非法或 0 长度回退默认值
- 随机数与随机串均取自系统密码学安全随机源，并做了取模去偏处理
- `randomInt` 的区间写反会自动交换（`9-1` 等价于 `1-9`）

### 5.4 编解码类

| 占位符 | 说明 | 结果示例 |
|-------|------|---------|
| `{{fn:base64:user:pass}}` | Base64 编码（UTF-8） | `dXNlcjpwYXNz` |
| `{{fn:md5:abc}}` | MD5 摘要（32 位小写十六进制） | `900150983cd24fb0d6963f7d28e17f72` |
| `{{fn:sha256:abc}}` | SHA-256 摘要（64 位小写十六进制） | `ba7816bf...f20015ad` |
| `{{fn:hmac-sha256:密钥:消息}}` | HMAC-SHA256 签名（64 位小写十六进制；写法 `hmacsha256` 等价） | — |
| `{{fn:urlEncode:a b&c}}` | URL 编码 | `a%20b%26c` |

`md5` / `sha256` 参数为空时返回空串。`hmac-sha256` 以**第一个冒号**分隔密钥与消息（消息可以再含冒号），密钥为空时返回空串。

### 5.5 嵌套：参数里可以再写占位符

动态函数的参数支持嵌套其他占位符，这是签名场景的关键能力：

```
{{fn:md5:{{env:appSecret}}{{fn:timestamp}}}}
{{fn:base64:{{env:appId}}:{{secret:appKey}}}}
{{fn:sha256:{{fn:nonce}}{{fn:timestamp}}{{env:salt}}}}
```

嵌套的求值依赖第 1 节的解析顺序：`{{input:}}` / `{{secret:}}` / `{{env:}}` 在动态变量之前已完成文本替换，`{{fn:}}` 之间则由动态解析器递归求值。

**同一次请求内的时间基准是一致的**：一次发送只取一次当前时间，所有 `{{fn:timestamp}}`（包括嵌套在 `md5` 参数里的那个）都得到同一个值。因此下面这种「签名 + 明文时间戳」的写法能够对得上：

```
X-Timestamp: {{fn:timestamp}}
X-Sign:      {{fn:md5:{{env:appSecret}}{{fn:timestamp}}}}
```

随机类函数不做复用——每处 `{{fn:uuid}}` / `{{fn:nonce}}` 各自独立取值。若签名需要与请求头中的 nonce 保持一致，请改用 `{{env:}}` 或 `{{input:}}` 传入同一个值。

### 5.6 动态变量与其他类型的区别

- **不弹输入框**：不会出现在运行时参数面板
- **不参与串联链映射**：创建串联链步骤时，映射面板会自动过滤掉 `{{fn:}}`，只列出可映射的变量
- **不需要预先定义**：与环境变量不同，动态变量是内置函数，直接写即可

### 5.7 函数测试工具

接口编辑页顶栏菜单提供「**函数测试**」（半模态「动态函数测试」），可在发送请求前预先验证动态函数的实际输出：

- 输入 `{{fn:...}}` 表达式或任意包含占位符的文本；未写 `{{ }}` 时会自动包裹一层
- 点击「运行测试」立即求值；无法求值时提示「表达式无效或函数名不存在」
- 结果支持一键复制
- 内置常用表达式预设（时间戳、UUID、随机数、摘要、HMAC 签名等），点击即测
- 仅解析 `{{fn:...}}` 动态函数：`{{env:...}}`、`{{input:...}}` 等其他占位符不会在此求值，会按字面文本参与计算

## 6. 串联链变量：无前缀 `{{key}}`

无前缀占位符由前置步骤的提取规则注入，是串联链的数据通道；可使用 `{{key|默认值}}` 为缺失映射提供后备值。

```
步骤 1  POST /login   提取规则 token = $.data.accessToken
步骤 2  GET  /user    Bearer Token 填 {{authToken}}
        映射面板：{{authToken}}  →  来源 token
```

添加步骤时系统自动扫描目标配置里的全部无前缀占位符，在映射面板左列列出，右列选择来源提取规则。

> 注入的值是前置步骤的提取结果。若来源接口配置了「正则清理」规则，注入的是**清理后**的值（详见《正则规则文档》）。

> 若来源结果为数组，注入方式由**来源步骤的完整提取结果**决定：来源步骤同时含单值与数组规则（或数组仅一个元素）时，整体按单值处理，数组以换行连接的完整文本注入，不弹选择面板；全部规则均为数组且等长时，执行到此步骤前弹出选择面板按行对齐选择，选中后按行迭代执行后续步骤；数组长度不等时，先对首组等长数组弹出面板，选中后**同一步骤内**继续弹出下一组面板，全部选完才开始执行该步骤。选中若干行后，来源步骤中与所选数组同长度的其他数组结果也会同步过滤为所选行，供后续步骤引用。来源模板引用的数组同样遵循该规则，选中行后占位符替换为所选行的单值。

> 注意：`{{步骤序号.规则名}}`（如 `{{0.token}}`）是另一套语法，只在串联链编辑页生效——用于步骤映射的「模板」来源与链「输出模板」，不能用在接口配置字段里。

## 7. 组合示例

### 7.1 开放平台签名请求

**环境变量**（当前环境）：

| 变量名 | 值 |
|-------|---|
| `host` | `openapi.example.com` |
| `appId` | `1000123` |
| `appSecret` | `s3cr3t`（勾选密文） |

**接口配置**：

| 字段 | 值 |
|------|---|
| URL | `https://{{env:host}}/v1/order/create` |
| 请求头 | `X-App-Id: {{env:appId}}` |
| 请求头 | `X-Timestamp: {{fn:timestamp}}` |
| 请求头 | `X-Nonce: {{fn:uuid}}` |
| 请求头 | `X-Sign: {{fn:md5:{{env:appId}}{{fn:timestamp}}{{env:appSecret}}}}` |
| 请求体 | `{"requestId":"{{fn:uuid}}","amount":"{{input:amount}}"}` |

发送时只需填一个 `amount`，其余全部自动生成，且 `X-Timestamp` 与签名中的时间戳一致。

### 7.2 幂等键与请求追踪

| 字段 | 值 |
|------|---|
| 请求头 | `Idempotency-Key: {{fn:uuid}}` |
| 请求头 | `X-Request-Id: {{fn:nonce:32}}` |
| 请求头 | `X-Trace-Time: {{fn:isoDate}}` |

每次点击发送都是全新的幂等键，便于重复压测同一接口。

### 7.3 时间窗口查询

| 字段 | 值 |
|------|---|
| 查询参数 | `startTime={{fn:datetime-86400:yyyy-MM-dd HH:mm:ss}}` |
| 查询参数 | `endTime={{fn:datetime:yyyy-MM-dd HH:mm:ss}}` |

固定查询「最近 24 小时」，配置一次长期可用。

### 7.4 与串联链协同

```
步骤 1  POST /auth/token
        请求体  {"appId":"{{env:appId}}","sign":"{{fn:sha256:{{env:appSecret}}{{fn:timestamp}}}}"}
        提取规则  accessToken = $.data.token

步骤 2  GET /user/profile
        Bearer Token  {{authToken}}          ← 映射到步骤 1 的 accessToken
        请求头  X-Request-Id: {{fn:uuid}}     ← 自动生成，不出现在映射面板
```

## 8. 排错

**字段值意外为空**

占位符未解析时会在请求发出前被替换为空字符串（见 2.4 节）。常见原因：函数名或变量名拼写错误（核对第 5 节函数表）、环境变量未在当前环境定义。注意前缀必须紧跟 `{{` 小写书写：`{{fn: timestamp}}` 中 `fn:` 后的空格会被忽略、不影响识别，但 `{{ fn:timestamp}}`（`{{` 后有空格）会被当作串联链变量；参数不做去空格处理，`{{fn:md5: abc}}` 的参数是 `" abc"`。

**签名校验失败**

依次确认：参数拼接顺序与服务端约定是否一致；摘要算法（md5/sha256）是否匹配；服务端要求大写十六进制时，本工具输出为小写，需要服务端兼容或换用其他拼装方式；时间戳单位是秒（`timestamp`）还是毫秒（`timestampMs`）。

**`{{env:}}` 提示未定义**

变量不在**当前环境**中。检查「环境变量」页是否已把目标环境设为「使用中」，以及变量名大小写是否完全一致；若希望请求仍使用确定值，可写成 `{{env:变量名|默认值}}`。

**嵌套占位符没被替换**

只有动态函数的**参数**支持嵌套求值。不要在环境变量名或运行时参数名里嵌套占位符，例如 `{{env:{{fn:date}}}}` 不会生效。

**串联链映射面板里找不到某个占位符**

只有 `{{fn:}}` 动态函数不参与映射（发送前自动求值，无需绑定）；`{{input:}}`、`{{secret:}}`、`{{env:}}` 同样会出现在映射面板中，可为它们绑定来源规则。注意运行时输入在链变量注入之后应用，同名时会覆盖链注入的值。

**默认值没有生效**

默认值只会处理仍未解析的完整占位符。确认竖线写在占位符内部，例如 `{{env:host|api.example.com}}`；环境变量与运行时输入已成功解析为空字符串时，空字符串会作为实际值保留，不会改用默认值（串联链变量提取结果为空字符串时例外，会走默认值兜底）。
